## Released changes

Production source: 112ad80, marker `odbiryani-2026-10-28-mobile-scroll`, published through GitHub main to Netlify.

- Replaced the scroll-linked spring/progress bar and changing blurred header with a stable opaque header. Removed header scroll listeners, scroll-driven resizing and entry animation.
- Removed gallery reveal/scale animations and the lightbox blur. Photos and headings remain visible without waiting for animation observers.
- Kept native scrolling and native anchor navigation. Disabled CSS smooth scrolling so it cannot compete with touch momentum or focus navigation.
- Preserved original kitchen photos and generated metadata-free WebP copies at bounded sizes. The five 640px copies total 398,210 bytes versus 6,145,992 bytes for the originals (94% smaller). Larger responsive variants remain available; the largest is 282,334 bytes. Each display image is below three million decoded pixels. Phones may select larger variants based on screen density.
- Added image transfer, decoded-size and metadata checks to the production build. Prices, private ordering, fulfillment selection and owner notifications retain their existing behavior.
